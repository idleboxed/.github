# idleboxed organization profile

The public GitHub organization profile for
[idleboxed](https://github.com/idleboxed), maintained in
[`idleboxed/.github`](https://github.com/idleboxed/.github).

Edit [profile/README.md](profile/README.md) and push to `main` to update the
organization overview. Keep this repository limited to the public profile;
it does not supply organization-wide workflow defaults or application builds.

The short organization description and website link are separate GitHub
organization settings. The website is maintained in
[`idleboxed/idleboxed.github.io`](https://github.com/idleboxed/idleboxed.github.io)
and published at <https://idleboxed.github.io/>.
